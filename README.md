# GodotAgentModellingSim
### Notes
This Readme file was generated by ChatGPT 5.2 and verified by Francis Spooner

## Requirements

- Ubuntu 24.04 (Noble)
- .NET SDK 8.0
- Godot 4.x **.NET (Mono)** build

Install system dependencies:
```bash
sudo apt update
sudo apt install -y \
  dotnet-sdk-8.0 \
  unzip \
  libsqlite3-0 \
  libstdc++6
```

---

## Godot (.NET)

Download Godot .NET:
```bash
wget https://github.com/godotengine/godot/releases/download/4.2.1-stable/Godot_v4.2.1-stable_mono_linux_x86_64.zip
unzip Godot_v4.2.1-stable_mono_linux_x86_64.zip
```

---

## .NET Dependencies

From the project root:
```bash
dotnet restore
dotnet add package DuckDB.NET.Data
dotnet add package ScottPlot
```

---

## Build

Godot will compile C# automatically, but you can pre-build:

```bash
dotnet build
```

---

## Run (Godot Editor)

1. Launch Godot:
   ```bash
   ./Godot_v4.2.1-stable_mono_linux_x86_64
   ```
2. Click **Import**
3. Select the directory containing `project.godot`
4. Open the project
5. Click the **Play (▶)** button

---

## Run (CLI / Headless)

```bash
./Godot_v4.2.1-stable_mono_linux_x86_64 --headless --quit-after 1
```

## Notes

- `Main.cs` is the runtime entry point.
- Output is written via `GD.Print` (stdout).
- DuckDB database files are created in the project directory unless configured otherwise.
- All file paths are resolved relative to the project root.
